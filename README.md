# 📊 Customer Churn Prediction | End-to-End Machine Learning Project

## 🚀 Project Overview
Developed an end-to-end Machine Learning application to predict customer churn and identify customers who are likely to discontinue a service. The project covers the complete ML workflow, including exploratory data analysis (EDA), data preprocessing, model training, evaluation, and interactive deployment using Streamlit.

## 🛠️ Tech Stack
- **Programming Language:** Python
- **Data Analysis:** Pandas, NumPy
- **Data Visualization:** Matplotlib, Seaborn
- **Machine Learning:** Scikit-learn
- **Deployment:** Streamlit
- **Development Tools:** Jupyter Notebook, VS Code

## 💡 Key Features

- **Exploratory Data Analysis (EDA):** Analyzed customer data and visualized churn patterns to identify potential factors associated with customer attrition.
- **Data Preprocessing & Feature Engineering:** Prepared the dataset by handling missing values, encoding categorical variables, and scaling numerical features where appropriate.
- **Machine Learning Model Development:** Trained and evaluated classification models, including Logistic Regression and Random Forest, to predict customer churn.
- **Model Evaluation:** Assessed model performance using appropriate classification metrics to compare predictive effectiveness.
- **Interactive Web Application:** Built a Streamlit application that accepts customer information and generates churn predictions, with probability estimates where supported by the model.
- **End-to-End Workflow:** Integrated data analysis, model training, model serialization, and application deployment into a single project.
