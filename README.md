# 📊 Customer Churn Prediction (End-to-End ML Project)

## 🚀 Overview
This project predicts whether a customer will churn (leave a service) or not using Machine Learning. It covers the complete ML pipeline—from Exploratory Data Analysis (EDA) and data preprocessing to model training and interactive deployment.

---

## 🛠️ Tech Stack & Libraries
- **Language:** Python 🐍
- **Libraries:** Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn
- **Deployment:** Streamlit (for building the interactive web application)
- **Environment:** Jupyter Notebook, VS Code

---

## 💡 Key Features
- **Exploratory Data Analysis (EDA):** Deep dive into customer behavior using data visualization to find patterns behind churn.
- **Feature Engineering:** Data preprocessing, handling missing values, and scaling features for model accuracy.
- **Machine Learning Models:** Implementation of classification algorithms (e.g., Logistic Regression / Random Forest) to predict churn probabilities.
- **Interactive UI:** A live Streamlit dashboard where users can input customer metrics and get real-time predictions.
